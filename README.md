# Embed Bot

Comando `/embed` com 3 opções:
- `embed` — texto da embed
- `nome` — nome do botão
- `link` — link do botão

No Railway, configure:
- TOKEN = token do bot
- CLIENT_ID = 1553988297963868251
- GUILD_ID = 1539043438568144926

O comando é registrado diretamente no servidor.

O bot precisa ser instalado com os scopes `bot` e `applications.commands`.

Nunca publique o TOKEN no GitHub ou no chat.
